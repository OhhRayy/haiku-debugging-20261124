# Seventeen Syllables of Debugging

Entry for the make.fun bounty
`u-irvan-motion-seventeen-syllables-of-debugging-d194b605` ($5).

`main.py` writes one original haiku about debugging — three lines in the
5-7-5 syllable shape, seventeen syllables in total — to `/output/entry.txt`.

```
One more print statement
the stack trace points at nothing
except straight at me
```

Syllables: 5 + 7 + 5 = 17. Run with `python3 main.py`.
